# XR Gaming Plugin (Blaxon fork)

![XR Gaming Plugin](./assets/store_image.png)

This is a fork of [wheaney/decky-XRGaming](https://github.com/wheaney/decky-XRGaming), the Decky Loader plugin that provides virtual display, VR-Lite, and Follow modes for [supported XR glasses](https://github.com/wheaney/XRLinuxDriver#supported-devices).

For installation instructions, the full controls reference, troubleshooting FAQ, Supporter Tier details, and everything else about the plugin itself, see the **[original repository](https://github.com/wheaney/decky-XRGaming)**. Everything there applies here unchanged, except as noted below.

## What's different in this fork

* **Recenter with a controller combo** — a dropdown in the plugin sidebar (next to **Recenter display**) lets you bind a controller button combo (e.g. R4, L1+R1, Steam+A) to trigger a recenter, without leaving Game Mode or touching a terminal/systemd. It keeps working mid-game, even when Steam Input has grabbed the controller. Select **Disabled** to turn it off.
